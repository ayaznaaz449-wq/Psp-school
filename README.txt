Deploy all files in this folder together to an HTTPS static host (for example GitHub Pages). Open the hosted site in a supported mobile browser and use Add to Home Screen / Install. Service workers and PWA install do not work from a local file:// URL. Offline cache works after the first successful visit. Voice search requires browser support and microphone permission. Bus tracking, predictor, and some UI are demonstrations, not live services. Replace student video placeholders with real videos only after school approval and parent/guardian consent.
